# Connect Four

A Connect Four game with a Minimax AI opponent built in Java.

## How to Run

Requirements: JDK 8 or higher

Steps
1. Clone or download this repository
2. Open a terminal in the project folder
3. Compile:
   javac Main.java GameLogic.java GameWindow.java BoardPanel.java
4. Run:
   java Main

## Features
- Minimax AI with alpha-beta pruning
- Score tracking
- Win highlight
- Clean modern UI
